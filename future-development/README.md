# 추후 개선 사항 — 독립 프로그램으로 발전될 가능성

[프로젝트 소개로 이동](../README.md)

## 확장 방향

현재 프로젝트는 Google Sheets·Apps Script·Google Slides를 연결한 보고서 자동화로 구현함. 이 구조의 데이터 처리와 보고서 배치 기능을 바탕으로, 별도 입력 화면과 작업 관리를 갖춘 독립 프로그램으로 발전시킬 가능성을 검토함.

프로그램 확장은 향후 설계 단계로 정리함. 기존 Node 기반 검증 코드와 보조 스크립트는 확장 방향을 검토할 때 참고할 자료로 분리 보관함.

## 프로그램으로 확장할 때 검토할 요소

| 요소 | 검토 방향 |
| --- | --- |
| 입력 화면 | 학생 검색·문항·점수·전달사항을 한 화면에서 관리 |
| 처리 모듈 | 데이터 조회·검증·보고서 배치·출력을 구분하고 Node.js 활용 가능성 검토 |
| Google 서비스 연결 | 실행 계정의 인증과 이미지·결과 파일 접근 권한을 연결 구조에 반영 |
| 작업 관리 | 여러 학생의 보고서 생성 요청과 진행 상태를 관리 |
| 결과 관리 | 시험·학생별 보고서 이력과 저장 방식을 설계 |

## Node 관련 참고 자료

[node](node/) 폴더에 기존 검증 코드와 보조 스크립트를 모아 둠. 이 자료는 향후 모듈 분리와 프로그램 구조를 검토할 때 참고할 수 있도록 구성함.

| 위치 | 내용 |
| --- | --- |
| node/tests | 데이터 처리·보고서 요청·창 상태를 확인하는 기존 모의 검증 코드 |
| node/scripts | 보고서 배치와 HTML 창을 다루는 보조 스크립트 |
| node/package.json | 참고 자료의 실행 명령 정의 |

기존 코드는 Google 서비스의 응답을 모의 객체로 대체하는 구조임. 독립 프로그램으로 전환하려면 실제 입력·저장·Google 인증 연결을 별도로 설계해야 함.

현재 포트폴리오의 구현 범위는 Google Workspace 기반 보고서 자동화로 설명하고, 이 폴더는 추후 프로그램 확장 가능성을 정리하는 영역으로 구분함.
