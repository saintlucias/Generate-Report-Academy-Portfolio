# 포트폴리오 설명문

[프로젝트 소개로 이동](../README.md)

## 프로젝트 소개

학원의 국어 모의고사 결과를 학생별 분석 보고서로 만드는 업무를 자동화함. Google Sheets에 학생 이름을 입력하고 버튼을 누르면 학생 정보, 문항별 결과, 영역별 점수 그래프, 교사 전달사항을 Google Slides의 정해진 위치에 배치하도록 구현함.

기존 보고서 양식과 입력 방식을 유지하면서 반복 입력을 줄이는 것을 목표로 함. 부분 글자색 보존, 재생성 처리, 생성 상태 표시와 계정별 접근 오류 진단까지 기능을 확장함.

## 문제와 요구사항

학생 데이터와 시험지 데이터가 별도 탭에 존재하고, 항목마다 읽어야 할 위치가 다른 문제가 있었음. 학생 정보와 전달사항은 선택한 학생 행을 따라가고, 평균 점수와 시험지 공통 설명은 고정 셀에서 읽도록 구분함.

교사가 입력한 빨강·파랑 강조 문구를 보존하고, 숫자 난이도는 검정 별표로 변환하도록 구성함. 학생과 평균의 다섯 영역 점수는 같은 오각형 그래프에서 비교하도록 설계함.

버튼 실행 후 생성 상태와 결과를 확인하고, 같은 학생을 재생성할 때 기존 보고서를 갱신할 수 있도록 구성함.

## 설계와 구현

### 데이터 조회와 보고서 배치 분리

조회·검증 단계에서 보고서용 객체를 만들고, 이를 좌표 모델과 Slides 요청으로 변환함. 시트 접근, 데이터 규칙, 도형 배치를 함수의 책임으로 구분함.

이름은 조회 조건으로 사용하고 수험번호를 갱신 식별자로 선택함. 동명이인은 수험번호와 학교를 기준으로 선택하도록 처리함.

### 기존 양식을 유지하는 출력

빈 PNG 양식을 배경으로 사용하고 텍스트와 그래프를 별도의 Slides 요소로 배치함. 생성된 텍스트와 도형을 편집 가능한 요소로 구성함.

고정 좌표 방식으로 기존 문서와 유사한 배치를 구현하고, 현재 적용 범위를 지정된 25문항 양식으로 한정함.

### 부분 글자색과 그래프

RichTextValue에서 부분 색상 구간을 읽고, 문자열 결합이나 줄바꿈 조정 후 색상 구간을 다시 연결함. 원본 색상을 유지하는 항목과 검정을 고정하는 난이도 항목을 구분함.

다섯 점의 좌표를 계산해 선과 삼각형으로 오각형 그래프를 구성함. 평균선 → 학생 면 → 학생선 순서로 배치하고 학생 면의 불투명도를 0.25로 설정함.

### 생성 과정과 실패 처리

HTML 창을 먼저 열고 서버 함수를 비동기로 호출함. 로딩 아이콘, 동명이인 선택, 보고서 열기, 오류 후 다시 시도를 같은 창에서 처리함.

재생성 시 새 페이지를 준비한 뒤 기존 페이지를 교체함. 문서 잠금으로 생성 요청을 조정하고 성공 여부, 결과 URL, 실패 단계를 기록함.

## 운영 문제와 해결

다른 사용자에게 파일 ID 관련 오류가 발생해 연결된 파일별 접근 권한을 확인함. 최종 원인을 Drive 이미지 접근 권한 설정에서 확인하고 해당 권한을 수정해 해결함.

이후 파일별 접근 검사와 단계별 오류 메시지를 추가함. 링크 공유 파일의 접근 키를 보존하는 처리도 보완해 같은 오류가 발생했을 때 확인할 대상을 구분할 수 있도록 개선함.

## 구현 결과

학생별 보고서 작성을 이름 입력과 버튼 실행으로 연결함. 입력값, 부분 글자색, 그래프와 메시지 배치를 일정한 규칙으로 처리하고 생성 결과와 오류를 기록하도록 구성함.

## 개선 방향

시험 ID를 활용한 월별 이력 관리, 설정 기반 열 매핑, 여러 학생의 생성 요청을 순서대로 처리하는 작업 큐를 다음 과제로 정리함.

## 짧은 소개 문구

Google Sheets·Apps Script·Google Slides를 연결해 학생별 국어 모의고사 분석 보고서를 자동 생성하는 도구를 구현함. 부분 글자색 보존, 편집 가능한 오각형 그래프, 수험번호 기반 재생성, 비동기 생성 창과 파일 접근 진단을 적용함.
