## 1. 다른 사용자에게만 발생한 파일 접근 오류

### 증상

다른 사용자가 보고서를 생성할 때 파일 ID 관련 오류가 발생함. 결과 슬라이드의 권한을 편집자로 변경한 뒤에도 같은 오류가 이어짐.

> 입력한 ID에 해당하는 항목이 없습니다. 이 항목을 수정하지 않았거나 액세스 권한이 없기 때문일 수 있습니다.

### 원인과 해결

사용자 확인 결과, 원인을 Google Drive 내부의 이미지 접근 권한 설정에서 확인함. 해당 이미지의 권한을 수정한 뒤 오류가 해결됨.

보고서 생성 과정에서 스프레드시트, 양식 이미지, 선택 로고, 결과 슬라이드에 각각 접근함. 실행한 사용자가 결과 슬라이드를 편집할 수 있어도 양식 이미지를 읽지 못하면 생성이 중단되는 구조임.

### 보완한 기능

| 보완 | 목적 |
| --- | --- |
| checkReportFileAccess | B2 양식·B4 로고·B5 결과 파일의 읽기·열기 결과를 각각 표시 |
| 실패 단계 추가 | 양식 읽기, 로고 읽기, 슬라이드 작성, 기록 저장을 구분 |
| 설정 셀·파일 ID 포함 | 같은 오류 문구에서도 확인해야 할 파일을 식별 |
| 이미지 접근 키 보존 | 전체 공유 링크에 있는 resourcekey를 파일 읽기에 전달 |
| 원래 오류 유지 | 추가 안내 때문에 실제 Google 오류가 가려지지 않도록 처리 |

파일별 접근 결과와 실패 단계를 구분해 동일한 오류 문구에서도 확인할 대상을 좁힐 수 있도록 개선함. 접근 키 처리는 링크 공유 파일을 위한 추가 보완이며, 실제 확인된 장애 원인은 이미지 접근 권한으로 구분함.

## 2. 원본 글자색과 출력 규칙의 충돌

과정 설명의 빨강·파랑 글씨는 보존하면서 난이도 별표는 검정으로 고정해야 하는 요구가 발생함. 일반 텍스트의 색상 처리와 난이도의 표시 규칙을 분리함.

난이도 문자열을 생성할 때 검정을 명시하고, 원본 난이도 셀의 색상과 관계없이 같은 색으로 출력되도록 수정함.

## 3. 그래프 눈금이 두 줄로 표시되는 문제

오각형 그래프의 20·15·10 같은 숫자가 좁은 텍스트 상자에서 두 줄로 나뉘는 문제가 발생함. 눈금 상자의 폭·높이와 정렬을 조정해 한 줄에 배치되도록 수정함.

## 4. 과정 열과 입력 셀 변경

요구사항 구체화 과정에서 과정은 D열 영역 태그 → E열 갈래 태그, 학생 조회 셀은 S7로 확정함. 학생 정보에는 D열 학교명을 연결하고 공통 설명은 시험지데이터 H27로 구분함.

학생 행에 따라 이동하는 데이터와 고정 셀에서 읽는 데이터를 분리해 연결표로 관리함.

## 5. 함수가 실행 목록에 보이지 않는 문제

기록의 오류 글자색을 갱신하는 함수가 실행 목록에 보이지 않는 문제가 발생함. 당시 적용된 코드에 해당 함수가 포함되지 않은 것을 확인함.

최신 전체 코드에 기능을 포함하고, 실행 대상 코드와 제공된 기능이 일치하도록 정리함.

## 6. 생성 중 상태와 결과 표시

별도의 HTML 창을 구성하고 서버 함수를 비동기로 호출해 로딩 → 완료 또는 오류 상태로 전환함. 생성 완료 시 보고서 열기 버튼을 제공하고, 실패 시 오류 내용과 다시 시도 기능을 표시함.
