# 입력 데이터와 셀 연결표

[프로젝트 소개로 이동](../README.md)

## 시트 구성

| 탭 이름 | 역할 | 입력 시작 |
| --- | --- | --- |
| 수험생데이터 | 학생 정보·오답·영역별 점수·전달사항 | 학생 레코드는 3행 |
| 시험지데이터 | 문항·태그·난이도·공통 설명 | 문항은 2행 |
| 보고서설정 | 이미지·결과 파일·그래프 설정 | 초기 설정으로 생성 |
| 보고서생성기록 | 생성 상태·결과 URL·오류 | 초기 설정으로 생성 |

탭 이름과 열 위치를 기준으로 데이터를 연결함. Apps Script가 연결된 스프레드시트에서 학생·문항·설정 데이터를 조회함.

## 학생 선택과 학생별 값

| 보고서 항목 | 수험생데이터 위치 | 처리 |
| --- | --- | --- |
| 조회할 이름 | S7 | C3:C의 이름과 앞뒤 공백을 제거해 비교 |
| 생성 버튼 | T6 위 이미지 | generateReportByName 실행 |
| 수험번호 | A3:A | 찾은 학생 행의 표시값 사용, 빈 값·중복 거부 |
| 학생명 | C3:C | 찾은 학생 행 사용 |
| 학교명 | D3:D | 찾은 학생 행 사용 |
| 틀린 문제 번호 | G3:G | 목록에 있는 문항은 X, 나머지는 O |
| 운문 문학 점수 | H3:H | 찾은 학생 행 |
| 산문 문학 점수 | I3:I | 찾은 학생 행 |
| 비문학 점수 | J3:J | 찾은 학생 행 |
| 문법 점수 | K3:K | 찾은 학생 행 |
| 초등 점수 | L3:L | 찾은 학생 행 |
| 담당 T 전달사항 | P3:P | 찾은 학생 행, 줄바꿈·부분 글자색 반영 |

조회한 학생과 같은 행의 수험번호·학교·오답·점수·전달사항을 사용함. 예를 들어 데모학생이 C12에 있으면 A12·D12·G12·H12:L12·P12를 연결함. 보고서 갱신은 수험번호를 기준으로 처리함.

오답 번호 목록에 포함된 문항을 X로 표시하고, 나머지는 O로 표시함. 빈 값·없음·대시는 모두 정답으로 해석함. 범위를 벗어난 번호, 음수·소수·범위 표기를 거부하고 중복 번호는 한 번으로 처리함.

## 문항별 값과 공통 설명

| 보고서 항목 | 시험지데이터 위치 | 처리 |
| --- | --- | --- |
| 문항번호 | A2:A26 | 1~25를 정확히 한 번씩 입력, 번호순으로 배치 |
| 과정 첫 줄 | D2:D26 | 영역 태그 |
| 과정 다음 줄 | E2:E26 | 갈래 태그, 영역 아래에 배치 |
| 난이도 | G2:G26 | 정수 1~4를 검정 ★~★★★★로 변환 |
| 회색 병합 영역 설명 | H27 | 학생 공통 설명, 줄바꿈·부분 글자색 반영 |

과정은 D열 영역 태그 아래에 E열 갈래 태그를 배치함. 문항 범위를 A2:G26으로 제한해 H27의 공통 설명과 구분함. H27이 비어 있으면 설명 영역도 비워 둠.

## 평균 점수와 그래프

평균 점수는 선택한 학생 행과 관계없이 다음 고정 셀에서 읽음.

| 축 순서 | 영역 | 파란 평균선 | 빨간 학생선 |
| --- | --- | --- | --- |
| 1 | 운문 문학 | 수험생데이터!M6 | 학생 행 H열 |
| 2 | 산문 문학 | 수험생데이터!M8 | 학생 행 I열 |
| 3 | 비문학 | 수험생데이터!M10 | 학생 행 J열 |
| 4 | 문법 | 수험생데이터!M12 | 학생 행 K열 |
| 5 | 초등 | 수험생데이터!M14 | 학생 행 L열 |

0 이상의 숫자를 유효한 점수로 처리함. 빈 값·음수·수식 오류를 거부하고, 고정 그래프 최댓값보다 큰 점수가 있으면 설정 오류로 안내함.

## 보고서설정

| 셀 | 항목 | 설정 |
| --- | --- | --- |
| B2 | 템플릿이미지 | 원본 3216 × 1960 PNG의 Drive 전체 공유 링크, 필수 |
| B3 | 학원명 | 국어 날개달기, 자동 갱신 |
| B4 | 로고이미지 | 선택 PNG/JPG/GIF의 Drive 전체 공유 링크 |
| B5 | 결과슬라이드 | Google Slides 링크, 비우면 최초 생성 시 새 파일 생성 |
| B6 | 그래프최댓값 | 빈 값이면 두 계열에 맞춰 자동 계산, 입력 시 양수 |
| B7 | 그래프제목 | 기본값: 모의고사 출제영역 |
| B8 | 보고서제목 | 한국 시간의 생성 월 + 월 모의고사 국어영역 분석표 |

양식 이미지와 선택 로고의 Drive 링크, 결과 슬라이드, 그래프 설정을 별도 탭에서 관리함. 전체 공유 링크의 resourcekey를 파일 접근에 함께 사용함.

학원명과 보고서 제목을 생성 시 자동 갱신함. 한국 시간의 생성 월이 11월이면 제목을 11월 모의고사 국어영역 분석표로 구성함.

## 생성 기록

| 열 | 내용 |
| --- | --- |
| A | 생성시각 |
| B | 수험번호 |
| C | 학생명 |
| D | 원본행 |
| E | 상태: 완료 또는 오류 |
| F | 슬라이드 URL |
| G | 오류내용과 실패 단계 |

완료 상태는 검정, 오류 상태는 빨강으로 표시함. 기존 오류 기록의 글자색을 일괄 갱신하는 기능도 지원함.
